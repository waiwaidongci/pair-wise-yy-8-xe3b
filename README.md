# 古法纸浆发酵 · 泡料用水巡查

运行：

```bash
npm start
```

访问 `http://localhost:3039`。数据保存在 `data/paper-pulp-fermentation.json`。

## 功能

- **入缸登记**：登记原料干重、初始水位（cm）、换水周期（天），随批次一起建档。
- **泡料用水巡查**：每次观察填写水位、酸碱度（pH）、是否换水；支持补录过去时间的巡查。
  - 水位低于初始值 **70%**，或距上次换水（入缸后未换水则自入缸起算）**超过换水周期**仍未换水，批次自动转「待补水」，记录原阶段，且不能申请抄纸。
  - 补齐换水记录、条件解除后自动回到原阶段（异常观察除外，按巡查结果重新计算）。
- **看板**：按缸位分组显示水位比例、距换水剩余/逾期天数、最新 pH 与巡查时间；巡查历史逐条保留，补录只追加，不覆盖旧记录。
