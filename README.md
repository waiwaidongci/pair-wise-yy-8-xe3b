# 古法纸浆发酵记录

运行：

```bash
npm start
```

访问`http://localhost:3039`。数据保存在`data/paper-pulp-fermentation.json`。

## 泡料用水巡查

- **入缸登记**：新增批次时填写原料干重、初始水位、换水周期。
- **每次巡查**：在「泡料用水巡查」表单填写观察日期、水位、酸碱度、是否换水；可补录过去日期，记录标记为「补录」，旧巡查只追加保留，不会被覆盖。
- **待补水规则**：水位低于初始水位七成，或超过换水周期未换水，批次自动转为「待补水」并记住原阶段，此时不能申请抄纸；补齐换水记录、水位恢复后自动回到原阶段。
- **缸位看板**：按缸位显示各批次当前水位比例与换水逾期天数。
